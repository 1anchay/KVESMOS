# Независимый аудит KVESMOS

Срез 26 ноября 2026. Ветка `codex/kvesmos-v15-galactic-adventure`, HEAD `5455cf3eed04c288f9911de064f88e40af80d8de`, [Draft PR №37](https://github.com/1anchay/KVESMOS/pull/37). Рабочее дерево содержит незакоммиченные карту, главу, фоновые изображения и интеграционный сценарий. APK, HEAD и рабочую копию нужно считать тремя сборками с разной доказательной базой.

## Вывод

Самый зрелый контур — самостоятельный урок с локальными данными, переходом к следующему действию и наградой. Игровой мир пока служит навигацией к этому контуру. Продолжать стоит с одной сцены, в которой движение значимо для игрока, и одной главы, чей прогресс выводится из реальных событий урока. Полный игровой движок и замена героев не требуются.

## Проверенные материалы

- В репозитории есть 300 основных JSON уроков по шаблону ID (EN 100, ES 60, DE 60, FR 40, ZH 40) и более 2 тыс. файлов под assets/audio. Количество материалов не подтверждает их педагогическое качество или воспроизведение на каждом устройстве. Уроки, редакторы данных и учебные APK проверяются отдельно от игровых локаций. [Исходники курсов](../../assets/courses) · [Инструменты](../../tool)
- QA APK `build/releases/KVESMOS-1.5-crew-motion-QA.apk` имеет 276 897 286 байт. aapt подтвердил `dev.orbitwords.orbitwords`, 1.4.2 / 24, minSdk 24, targetSdk 36. SHA-256 совпал с соседним файлом: `c8d8e99f50ea9820e101f04fed57df8cae34bf89923179ade5bf3ba0cd88d11d`. В ZIP лежат `bridge_lights.webp` и `world_0.webp`, но отсутствует `observatory.webp`. Наличие изображения в архиве не доказывает связанный экран. Подпись повторно проверена apksigner: сертификат QA SHA-256 b8c558730dd20651119dd74b014b31ff51f076af208198dc79e05e51a0dca8be. Установка и запуск подтверждены предыдущими логами. Новый запуск не выполнен: ADB не смог запустить сервер, подключённый QA-эмулятор в этом сеансе не подтверждён.
- Пересмотрены сохранённые Android-кадры и метаданные девяти роликов длительностью 13,28–13,51 с. Источник — `build/releases/KVESMOS-illustrated-crew/`, подпапки `idle-cycles/`, `miko-bridge/`. Галерея по исходнику демонстрирует покой, верный ответ и поддержку. Записанный прогон `.tools/crew-final-cast.log` дал 7 033 кадра, build p95 5,533 мс, raster p95 19,855 мс. Это эмуляторный debug-прогон, не оценка FPS на телефоне. `.tools/crew-idle-memory.log` содержит PSS 276 561–365 032 КБ в разных снимках без изоляции сцены.
- Для HEAD все три проверки PR завершились ошибкой. Quality сообщил 549 passed, 2 failed, 2 skipped. Локальный `.tools/crew-final-map-test.log` рабочего дерева показывает 5 passed / 2 failed, обе версии 390dp. Этот прогон содержит 10-минутный тайм-аут и `Bad state: No element` при получении первого Scrollable, поэтому требуется отдельно воспроизвести первичное зависание и состояние страницы, а не исправлять только сообщение об ошибке.
