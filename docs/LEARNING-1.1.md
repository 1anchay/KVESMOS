# KVESMOS 1.1

Новая ветка основана на релизе 1.0 `2de33a749bd23e91fdc9de76cba81701702e546c`. В APK 1.1 входят прежние 220 уроков и шесть режимов практики.

- «Слова по картинкам» в разделе «Практика → Слова». Тридцать оригинальных векторных иллюстраций отрисовываются в `lib/ui/picture_art.dart`. Переводы и связи с учебным материалом заданы в `tool/picture_words.txt` и `tool/compile_picture_words.py`. Карточка доступна после прохождения урока с соответствующей лексикой. В языках, где конкретное слово не встречается, оно не предлагается. Пул по курсам: EN 25, ES 21, DE 25, FR 23, ZH 26. После ответа видны артикль, варианты и пиньинь, где применимо. Ответы обновляют SM-2 без XP. Голосовой ввод заполняет редактируемое поле.
- Необязательная диагностика из восьми заданий действующего курса. Открывается при выборе точки старта или из списка языков. Рекомендация сохраняется локально. Уроки считаются пройденными после обычных занятий.
- Разбор ошибок опирается на конкретный ответ и грамматический контраст. Добавлены примеры для пяти языков, включая ser/estar, Akkusativ, элизию и китайские счётные слова. При других ответах используются авторские объяснения уроков. После нескольких ошибок итог урока предлагает повторить трудные слова в существующей практике.
- Десять авторских разговоров с двумя ветками и тремя решениями в каждом. Доступны после связанного урока и через практику диалогов. Выбор меняет ответ героя, уточнение и заключительную реплику. Есть перевод, текстовый ответ и пиньинь. Разговор сохраняется отдельно от XP и сундуков.
- Календарь на 30 дней в разделе «Прогресс». По каждой дате показаны XP и завершённые уроки текущего курса. Галочки вычисляются по текущей цели дня. Даты берутся из записей занятий, серия считается по календарным дням.

Новые состояния хранятся в таблице настроек по отдельным ключам курса. Схема SQLite, идентификаторы уроков и черновики 1.0 сохраняются. Иллюстрации и тексты сцен созданы для KVESMOS, сторонняя графика не импортирована.

Проверка на Android запускается командой `flutter test integration_test/learning_polish_demo_test.dart -d emulator-5556`. `tool/capture_learning_polish.py` снимает кадры и видео на отдельном `KVESMOS11_QA` по меткам теста. Демонстрационные данные находятся в памяти теста. QA APK собирается из `lib/main.dart` с существующей тестовой подписью.
