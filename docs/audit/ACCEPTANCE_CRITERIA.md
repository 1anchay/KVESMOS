# Критерии приёмки

Это целевые пороги для следующей реализации. Зафиксировать сравнимую базу и профиль устройства до изменения бюджетов.

| Проверка | Критерий и метод |
|---|---|
| Совместимость | 300 уникальных прежних lesson ID и пять языков. Обновление поверх QA со старой схемой без очистки. Проверить XP, незаконченный урок, инвентарь, один открытый и один ожидающий сундук, тему и напоминания. Сопоставить записанные состояния до и после. |
| Честные награды | Глава: новому, ветерану и пользователю, завершившему весь курс, в том числе в авиарежиме. Перезапуск на каждой стадии, двойное касание, повтор перехода, импорт одного файла дважды дают одинаковое состояние для одинакового результата и ноль лишних XP/грантов. |
| Полный цикл | Непрерывное видео вход → разговор → консоль → карта → берег → задача → возвращение → фактическая награда/запись. Не теряется быстрый переход к обычному уроку. |
| Анимации | Для всех девяти указать покой, blink, дыхание, взгляд, walk/fly, talk loop, greeting, joy, surprise, think, support, celebrate и prop action. На каждом ролике 10–20 секунд видны минимум покой, осмысленный жест и реакция. Для прочих клипов — главы видео или дополнительные ролики; отметка о показе привязана к ID клипа. В idle видны независимые траектории деталей. Стопа скользит максимум на 2% роста при опоре; у предмета расхождение точки контакта не более 3% роста. Переход к речи ≤150 мс после playback event и возврат ≤250 мс после конца или отмены. Это критерий реакции на речь. |
| Изображение | 48/96dp и крупный план без белой подложки, обрезанных глаз и неоднозначных масок. Светлая/тёмная темы, 320dp и 200% текста, системный reduced motion. Два человека по-прежнему распознаются по силуэту в масштабе урока. |
| Карта и двери | Панорамирование, pinch, reset, TalkBack, эквивалент доступа из текстового списка. Закрытый путь визуально и логически закрыт. Дверь имеет отдельную зону, даёт видимую реакцию и восстанавливает позицию при возврате. |
| Производительность | На физическом 60 Гц Android в profile три 60-секундных прогона после прогрева. Цель build/raster p95 ≤16,7 мс и ≤5% медленных кадров по FrameTiming. Отдельно загрузка. Измерение PSS на одной стадии и после десяти циклов перехода. Цель рост ≤25 МБ после прогрева и возврата, первые художественные дополнения ≤12 МБ сжатых ассетов. Отчёт указывает устройство, ABI, SHA и режим. Эмулятор — отдельный smoke. |
| Озвучка и управление | Все пять языков в авиарежиме. Старт, стоп, повтор, смена говорящего, сворачивание, потеря аудиофокуса, отказ разрешений и устройство без системного голоса. Понятные текстовые варианты, без ложного объявления оценки произношения. |
| CI и сборка | Формат, анализ, полный тестовый набор, Android-сценарии и успешные GitHub Checks на точном SHA. APK с прежним package ID, QA-подписью и опубликованной контрольной суммой для проверки. Подписанный RuStore-релиз и ключи остаются прежними. |
| Права | Реестр для каждого нового стороннего файла и сохранённый LICENSE, происхождение утверждённых/сгенерированных ассетов, исходники и воспроизводимые команды. |

Уровни доказательства: код и формат → тест в приложении → визуальная и звуковая приёмка на физическом телефоне. Указывать каждый применимый уровень отдельно. Существующий отчёт о 7033 кадрах в debug не заменяет третий уровень.
