# KVESMOS 0.4.0-dev.3+6 — учебный цикл

Ветка: `feature/lesson-coaching-voice-honesty`. [Draft PR #1](https://github.com/1anchay/KVESMOS/pull/1). Изменения не объединены с main.

## Что изменилось

- Первые шесть уроков: знакомство, происхождение, предметы, дом, количество и возраст. Всего 60 упражнений; в каждом уроке 7–9 механик, 3–4 вводных шага, цель, подсказки и объяснения. Первые три урока отредактированы, следующие три написаны в том же формате. Остальные 14 уроков сохранены, но ещё не прошли такую переработку.
- Вводные карточки: закреплённая кнопка перехода, возврат, медленное прослушивание, восстановление шага. Финальная сцена показывает самостоятельную реплику ученика; завершение — приобретённый навык и лучшую серию ответов.
- Десять состояний персонажа: ожидание, приветствие, речь, слушание, размышление, верный ответ, поддержка, празднование, удивление и прощание. Используются готовые позы, наклон, подпрыгивание, переходы, частицы и индикаторы. У Орби есть моргание на подготовленной позе. Движение при речи связано с событиями плеера. Учитываются настройка реакций и уменьшение движения.
- Локальные записи имеют приоритет над TTS; предусмотрены замедление, громкость, прерывание и сообщения об ошибках. В текущем manifest **0 записей**. Девять профилей героев не выдаются за девять отдельных голосов: число реальных системных голосов зависит от устройства. Без доступного голоса остаётся текст. [ТЗ на недостающие ресурсы](VOICE-AND-ANIMATION-ASSETS.md) и [34 учебные реплики для записи](audio/voice-script.tsv).
- Разбор ошибок использует существующие события и WordProgress/SM-2. Показаны трудные слова, сроки повторения и объяснение из материала, на котором ученик ошибся. Серии восстанавливаются из событий. Формула XP и правила интервалов не изменены.

## Совместимость и проверки

Идентификаторы Android/iOS, схема SQLite v1, старые пакеты, сессии и события сохранены. Новые материалы закрепляются за новыми сессиями; начатый урок не подменяется при обновлении.

- Локально: **92 теста успешно**, с покрытием. Проверены шесть уроков через интерфейс, звук и прерывания, отказ микрофона, анимации, повторение и открытие прежней базы. Анализатор и строгое форматирование проверяются перед отправкой и в CI.
- Android: собран ARM64 APK; актуальная x86_64 сборка запущена на Android API 36. Проверено обновление `versionCode 5 → 6` через `adb install -r` с совпадающим сертификатом и предварительным архивом данных.
- На отдельном эмуляторе использована синтетическая база: 130 XP, одна ошибка, завершённый и начатый урок, черновик, открытая награда и экипировка. После обновления все прежние строки таблиц совпали: 20 пакетов, 2 сессии, 13 событий, 4 настройки. Интерфейс восстановил задание 2/10 и черновик. Реальные данные телефона не затрагивались.
- CI выполняет строгое форматирование, анализ и тесты; Android Preview собирает `lib/main.dart` для ARM64 и публикует APK, SHA-256 и сертификат. Статус конкретного финального коммита и ссылки на артефакт фиксируются в PR после завершения Actions.

## Ограничения

Полного скелетного рига, независимых слоёв рук/головы и синхронизации губ нет: ZIP содержит в основном цельные изображения. Подготовлен расширяемый интерфейс кадров, но отсутствующие ресурсы не заменялись новой генерацией.

Студийные записи и отдельные локальные модели голосов не добавлены. Код маршрутизации записей проверен тестами, но воспроизведение реальных студийных файлов потребует файлов и проверки на устройстве. Слышимость TTS на физическом телефоне не проверена; эмулятор работает без аудиовывода.

iOS-код локального плеера добавлен, но Xcode-сборка и испытания iPhone на Windows не выполнены. IPA не выпускался. Проверки магазинов, облака и полноты курса A1 не объявлены пройденными.

Для Preview используется постоянный ключ владельца через GitHub Secret. Ключи и резервные копии не входят в репозиторий. Старый APK из CI, подписанный случайным ключом, нельзя безопасно обновить этим ключом без исходного ключа. Не удаляйте установленное приложение для обхода несовпадения подписи. [Проверка и обновление с резервной копией](SAFE-UPDATE.md).
