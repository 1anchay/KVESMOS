# KVESMOS — Галактика знаний

Текущая проверочная сборка: **0.7.0-dev.1+9 — Учебное путешествие**. Пять областей, уроки с контрольной точкой, персональные остановки памяти, паспорт открытий, добровольные экспедиции и восемь мини-историй с реакциями героев. [Сравнение 0.6 → 0.7, видео и проверки](docs/LEARNING-GAME-0.7.0.md), [Alive Experience 0.6](docs/ALIVE-0.6.0.md), [карта навыков](docs/A1-SKILLS.md), [безопасное обновление](docs/SAFE-UPDATE.md). Существующие 20 уроков, офлайн-речь и пользовательский прогресс сохранены.

Бесплатное приложение для изучения английского русскоговорящими. Flutter / Dart, Material 3, Riverpod, GoRouter, SQLite / Drift и необязательная синхронизация Supabase. Прежнее название — OrbitWords; технические идентификаторы сохранены для совместимости. Товарные знаки не проверялись.

Первая рабочая версия с настоящим учебным циклом и сохраняемым прогрессом. Перед публичным выпуском нужны редактура курса, испытания физических устройств и облачный приёмочный тест. Оплаты, рекламы, лимита ошибок и платных API нет. Эксплуатация облака и аккаунты магазинов могут потребовать расходов владельца; они не приобретались.

## Запуск

Проверяемая версия: **Flutter 3.47.7 / Dart 3.13.5**. Для Android нужны SDK API 36, NDK 28.2.13676358, JDK 21. Зависимости зафиксированы в `pubspec.lock`.

```sh
flutter pub get
dart run build_runner build
flutter run
```

В подготовленной Windows-папке Flutter находится в `.tools/flutter`. Обёртка учитывает системный прокси и исключает localhost:

```powershell
.\tool\flutter.ps1 doctor -v
.\tool\flutter.ps1 run -d <device-id>
```

База создаётся автоматически в application support directory. При первом запуске встроенные уроки последовательно устанавливаются в SQLite. Регистрация и сеть не нужны.

## Реализовано

- Онбординг, курс, стартовый уровень, дневная цель и профиль.
- Два раздела, десять тем, двадцать уроков и 200 оригинальных упражнений всех десяти типов.
- Проверка, объяснения, повторные попытки, восстановление черновика и позиции урока после закрытия.
- 60 слов, адаптация SM-2, повторение по сроку и добровольная практика.
- XP, уровни, серии, шесть достижений, дневные задания и статистика.
- Светлая / тёмная темы, масштабирование текста, оригинальный робот Орби и иконки.
- Нативные TTS, необязательное распознавание речи, текстовая альтернатива и локальные напоминания.
- Офлайн-пакеты из встроенного набора: удаление и восстановление локальных копий.
- Код регистрации, входа, восстановления пароля, удаления аккаунта и синхронизации; SQL RLS и серверная функция. Реальный Supabase-проект не подключён.

20 уроков знакомят с основами A1, но не подтверждают владение полным уровнем CEFR. Выбор стартового уровня не является тестом знаний. В версии 0.1 нет удалённого каталога новых курсов. Другие языки не объявлены готовыми.

## Проверки

```sh
flutter analyze
flutter test --coverage
dart format --output=none --set-exit-if-changed lib test
flutter build apk --debug
```

SQLite-тестам на Windows нужен `sqlite3.dll` в PATH или переменная `SQLITE_TEST_DLL`. На этой машине используется библиотека установленного Python:

```powershell
$env:SQLITE_TEST_DLL='C:\Program Files\Python310\DLLs\sqlite3.dll'
.\tool\flutter.ps1 test --coverage
```

Нативный игровой сценарий: `flutter test integration_test/alive_journey_test.dart -d <QA-emulator-id>`. Запускать только на выделенном QA-эмуляторе после резервного копирования: Flutter runner может переустановить пакет. Затем восстановить основную сборку и тестовые данные. Старый `integration_test/app_test.dart` очищает данные и для проверки обновления не применяется.

Фактические результаты и ограничения: [docs/STATUS.md](docs/STATUS.md).

| Путь | Назначение |
|---|---|
| `lib/domain/` | Контент, ответы, XP, серии, SM-2 |

## Облако и выпуск

[Настройка Supabase](docs/SUPABASE.md). В клиенте допустим только публичный ключ:

```sh
flutter run --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
```

`SUPABASE_ANON_KEY` принимает publishable или legacy anon key. Service-role / secret key в Flutter запрещён.
