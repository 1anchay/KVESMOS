# KVESMOS 1.2 Smart Learning

## Перенос между телефонами

1. Откройте «Настройки» → «Сохранение и перенос прогресса» → «Экспортировать».
2. В системном окне Android выберите личную папку. Дождитесь сообщения о сохранении. Перенесите JSON на второй телефон, например по USB.
3. На новом телефоне откройте перенос с экрана приветствия или из настроек. Выберите файл, проверьте предварительный расчёт XP и нажмите «Объединить прогресс».

Версия 1 контейнера содержит схему базы, время копии и SHA-256 содержимого. Хеш обнаруживает повреждение файла и не подтверждает его происхождение. Максимальный размер 32 МиБ. Файл открытый, содержит имя, историю занятий и черновики. Храните его в доступном только вам месте. KVESMOS использует системный выбор Android без широкого доступа к файлам, регистрации и фоновой отправки копии. Файл не включает токены, идентификатор облачного аккаунта, ключи, локальные разрешения Android и назначенные устройству голоса.

События объединяются по устойчивым ID внутри транзакции SQLite. XP, словарь, серия и достижения пересчитываются из истории. Сундук с одним ID остаётся одним сундуком. Если на двух телефонах из него уже выпали разные предметы, оба сохраняются как найденные, без нового открытия. Импорт добавляет отсутствующие офлайн-пакеты. Сессия с тем же ID сохраняет более поздний шаг и его черновик, при равном шаге приоритет у локального черновика. Прочие одноимённые настройки заполненного профиля остаются локальными. На чистом профиле восстанавливаются настройки и экипировка из файла. Несовместимые или повреждённые копии отклоняются. Системное разрешение на уведомления выдаётся отдельно на каждом телефоне.

### Старые версии и разные подписи

Android разрешает обновление на месте при совпадающем package ID и сертификате. Для тестовой 1.0 или 1.1 сначала обновитесь до 1.2 с тем же **тестовым** сертификатом и экспортируйте данные. Сохраните копию вне каталога приложения и откройте её в предпросмотре для проверки. Для будущей версии с другой подписью установите её на другом телефоне или только после резервного копирования удалите тестовое приложение. Импорт возможен в версии с поддержкой того же формата. Подписанная версия RuStore 1.0 не содержит меню экспорта. Её данные останутся доступны при обычном обновлении до будущей версии с тем же production-сертификатом.

## Рекомендации и аудио

«Практика» показывает основания рекомендации на выбранном курсе. За 30 дней учитываются разные задания по навыку, последний ответ определяет текущую трудность, а ошибка сохраняется в истории. Тренировка использует знакомые задания и расписание SM-2, сохраняет черновик и не начисляет XP или сундуки. При отсутствии истории предлагается первый доступный урок. Статистика показывает подтверждённые ответы, а для аудирования требуется завершённое воспроизведение до ответа без открытого текста.

В аудиодиалогах по две ситуации на каждый язык и по два вопроса. Английский, испанский, немецкий и французский используют 18 новых синтетических AAC-реплик из уже применяемых моделей Kokoro и Piper и, где текст совпадает, существующие клипы. Лицензии перечислены в манифесте голосов. Замедление новых клипов делается локальным плеером без смены высоты тона. Для путунхуа нужен установленный локальный голос Android. При его отсутствии доступно чтение с иероглифами и пиньинем. Текстовый режим не записывает ответы как аудирование. Голосовой ввод в разговоре добровольный, выводит редактируемый текст и не оценивает произношение.

## Проверка на телефоне перед выпуском

- На двух устройствах с совместимыми сборками проверьте экспорт в Downloads, импорт, повторное объединение, возобновление черновика и открытый сундук.
- В авиарежиме прослушайте обе скорости в четырёх языках со встроенными клипами. Для путунхуа проверьте режим с установленным офлайн-голосом и без него. Прервите реплику и убедитесь, что она не открыла вопрос как прослушанный.
- На узком экране при 200% масштабе проверьте порядок фокуса TalkBack, элементы выбора документа, варианты ответа и доступность пояснения. Откажите в доступе к микрофону, затем завершите разговор текстом.
