# Выпуск KVESMOS 1.0 в RuStore

## Подписание на Windows

Из корня проекта в PowerShell запустите:

```powershell
$env:JAVA_HOME = 'C:/Program Files/Eclipse Adoptium/jdk-21.0.7.6-hotspot'
.\tool\sign_rustore.ps1
```

Скрипт берёт проверенный APK из `build/releases/rustore/`. Если постоянного ключа ещё нет, введите `CREATE`, затем задайте пароль в приглашении Java. Запишите пароль в менеджер паролей. Файл ключа будет в `%USERPROFILE%\KVESMOS-private\rustore-release.p12`. Сделайте зашифрованную резервную копию вне репозитория. Сохраните этот ключ для обновлений. Если уже существует согласованный ключ KVESMOS, передайте параметры `-Keystore` и `-Alias`. Пароли вводятся интерактивно. Не отправляйте пароль и ключ в чат, GitHub или RuStore.

На выходе появятся `KVESMOS-1.0.0-RuStore-release.apk`, `SHA256SUMS-release.txt` и `release-certificate.txt`. Скрипт проверяет идентификатор, версию, target API, выравнивание и сертификат. До подписания в папке есть только `KVESMOS-1.0.0-RuStore-unsigned.apk`.

Новая подпись несовместима с установленной версией с тестовым сертификатом. Проверьте новый APK на отдельном телефоне или профиле. Прежнюю установку с прогрессом сохраните. Офлайн-версия не переносит прогресс между разными сертификатами.

## Карточка и загрузка

1. В RuStore Консоли откройте «Приложения», создайте KVESMOS, выберите мобильную версию и «Загрузить версию». Выберите подписанный APK. Package `dev.orbitwords.orbitwords`, версия `1.0.0`, код `18`, Android 7.0 и новее.
2. Перенесите название и описания из [LISTING-RU.md](LISTING-RU.md). В «Что нового?» укажите «Первый выпуск KVESMOS. 220 уроков на пяти языках, повторение слов, задания и награды». Поддержка — `vtar4a@gmail.com`. Категория — обучение или образование, если такой пункт доступен. Возрастную маркировку выберите по фактическому содержанию.
3. Загрузите `rustore-media/icon.png` (512×512) и четыре вертикальных скриншота в порядке номеров. Это реальные экраны Android-сборки 1.0 с эмулятора.
4. Укажите [публичную политику конфиденциальности](https://github.com/1anchay/KVESMOS/blob/release/kvesmos-1.0-android/docs/store/RUSTORE-PRIVACY.md). Она также открывается из настроек. Версия RuStore хранит профиль и прогресс на устройстве, без аккаунтов. Удаление локальных данных доступно в настройках. Микрофон нужен для голосового ответа, уведомления — для добровольных напоминаний, загрузка после перезагрузки — для восстановления расписания.
5. Проверьте подписанный APK по [памятке телефона](PHONE-QA.md), затем сохраните карточку и отправьте на модерацию из своего аккаунта. Для модератора укажите, что все уроки доступны без входа, для микрофона предусмотрен текстовый ответ.

Официальные инструкции — [загрузка и карточка](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication), [подпись](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/apk-signature), [модерация](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps).
