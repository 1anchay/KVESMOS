# KVESMOS 0.15 — продолжение программы

База: 160 уроков ([аудит](CURRICULUM-0.15-AUDIT.md)). Добавлены 60 занятий, 510 упражнений и 240 учебных реплик. Итого: 220 уроков, 2020 упражнений. Это учебная последовательность, без заявления о полном уровне CEFR.

## Предпосылки и последовательность

- EN: изученные прошлое, планы и просьбы → результат/опыт → длительность → относительные предложения и фон события.
- ES: настоящее и планы → завершённое прошлое estar → правильные формы → ir/hacer/tener → связный рассказ.
- DE: порядок слов, модальные и weil → Perfekt с haben/sein → вопросы → war/hatte → dass.
- FR: планы, отрицание и количества → Passé composé с avoir/être → вопросы и отрицание → фон Imparfait → сравнение и причины.
- ZH: счётные слова, время и частота → 已经/正在 → 完/还没 → 过/比 → 快要/先…再 → результат 听懂/找到. Европейские времена не переносятся в китайскую грамматику.

## Редакторские проверки

У каждого занятия отдельные цель, четыре примера, диалог с вопросом по смыслу и исправление ошибки с объяснением. Введение содержит распознавание смысла и сборку ответа. Основная часть чередует разговор, аудирование или повторение в начале; затем — исправление и самостоятельное воспроизведение. В последнем упражнении/разминке используется реальная предыдущая тема. В каждом занятии 8–9 упражнений, 7–8 типов. Китайские фразы снабжены пиньинем с тонами; предложения для сборки размечены смысловыми группами.

Проверены вручную согласование, порядок слов, формы прошедшего, переводы, соответствие диалогов ответам и постепенность правил. Автоматический аудит проверяет ID, каталог, ответы, варианты, токены, связи со словарём и неизменность прежних payload. Это внутренняя редактура, не независимая проверка носителями. До 1.0 остаётся внешняя проверка формулировок и прослушивание всех синтетических голосов.

Новые вводные формы (например, booked/gebucht и итоговые сочетания) сначала предъявляются как готовые реплики, затем систематизируются. Французское arrivées в FR32 дано для двух путешественниц; диалоги могут содержать контекстные формы для понимания, которые не требуют самостоятельного воспроизведения.
