# KVESMOS 1.4.1 — проверка на Android

Используйте QA APK только для установки поверх сборки с тем же тестовым сертификатом. Если Android сообщает о несовпадении подписи, остановитесь: удаление установленной версии может удалить её локальные данные.

1. Откройте **Настройки → Проверить звук и микрофон**. Выберите каждый из пяти языков, нажмите «Послушать» и «Медленно». Запишите, слышен ли звук и какой источник показывает экран. Для путунхуа при отсутствии голоса установите офлайн-голос Android.
2. Для английского и испанского нажмите «Проверить микрофон офлайн» и разрешите доступ. Скажите фразу и дождитесь текста. При сбое запишите точное сообщение, модель телефона, версию Android и состояние локального распознавателя. Запись и сам произнесённый текст для отчёта не нужны.
3. При отсутствии локального распознавателя можно отдельно разрешить системное распознавание. Служба Android может обрабатывать речь по сети. После проверки разрешение можно отключить на том же экране.
4. В письменных заданиях раскройте «Символы и клавиатура». Проверьте ñ и á на испанском, ß на немецком, ç на французском и иероглифы в китайском задании. Android может оставить текущую раскладку, даже если приложение передало нужный язык.
5. В профиле проверьте уровень и число завершённых уроков при переключении курса. Уровень берётся из диагностики, а подтверждённые недавние навыки показаны отдельно.
