# KVESMOS 1.0 Android — подготовка релиза

База: `9558b63589da2e4d6d5e21f6dd71466295ecd53e`, PR #22. Интеграционная ветка: `release/kvesmos-1.0-android`; целевая база Draft PR — main. Автоматическое объединение и отправка в магазины не разрешены. Функциональность заморожена: 220 уроков, пять языков, прежние механики.

## Подпись

`android/key.properties` отсутствует. Обычная release-сборка по-прежнему требует согласованный ключ. Переменная `KVESMOS_UNSIGNED_RELEASE_AUDIT=true` разрешает только техническую упаковку без подстановки debug-ключа. Неподписанные результаты нельзя устанавливать или подавать как готовый релиз.

Предлагаемая схема: владелец хранит постоянный app signing key и резервные копии вне репозитория; этим ключом подписывается APK RuStore, тот же ключ передаётся в Play App Signing по защищённой процедуре. Для последующих загрузок AAB используется отдельный upload key. Решение о создании ключей ещё не согласовано; ключи не создавались.

Установка с прежней debug-подписью несовместима с новым публичным сертификатом. Не удалять пользовательское приложение. Перенос прогресса требует отдельно проверенного сохранения/восстановления данных; наличие облачной синхронизации не гарантирует перенос локальных черновиков и настроек.

Источники, проверенные 12 ноября 2026:
- https://developer.android.com/studio/publish/app-signing
- https://developer.android.com/google/play/requirements/target-sdk — API 36 для новых обычных Android-приложений.
- https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/apk-signature

Release APK/AAB, 16-КБ выравнивание, release-производительность, полный Android E2E, аккаунты/удаление на реальном backend, публичная политика, карточки магазинов и финальный CI ещё требуют выполнения. Физический телефон и проверка носителями не подтверждены. Успешные проверки 0.15 не выдаются за проверку новой release-сборки.


## Промежуточная техническая проверка 12 ноября

Настоящий неподписанный release AAB успешно собран: 117866818 байт, SHA-256 `074e8e227cb4bda2574ecc9fca268794d2a451cb768027a959f22e11a565f233`. Это технический артефакт, не подписанный магазинный выпуск. Проверены все 220 уроков, отсутствие debug kernel и комплектность engine/app для каждой ABI. Выравнивание LOAD-сегментов 64-битных ELF не меньше 16384. Это не заменяет тест устройства с 16-КБ страницами.

Первый APK, собранный с target-platform ARM64, включал вспомогательные библиотеки других ABI без движка. Публичным артефактом не используется. CI и локальная сборка переведены на универсальный release APK; аудит теперь отвергает неполные наборы ABI.

Защита удаления аккаунта: успешный HTTP-статус без явного `deleted: true` не разрешает локальную очистку. Шесть адресных тестов удаления и синхронизации прошли. Реальная серверная конфигурация пока не проверена.
