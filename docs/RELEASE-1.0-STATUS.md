# KVESMOS 1.0 для RuStore

- Версия `1.0.0+18`. Package `dev.orbitwords.orbitwords`. Целевой API 36, минимальный API 24. Универсальный release APK проверяется в CI.
- Карточка, четыре реальные скриншота Android и утверждённая иконка подготовлены. [Инструкция RuStore](store/RUSTORE.md) и [политика](store/RUSTORE-PRIVACY.md).
- Режим сборки `KVESMOS_RUSTORE=true` отключает серверный вход и синхронизацию. В настройках есть ссылка на публичную политику. Все пять курсов работают с локальным прогрессом.
- На эмуляторе проверено обновление 0.15 → 1.0 с прежней тестовой подписью. Сравнение SQLite подтвердило 240 прежних настроек, 220 пакетов, четыре сессии и 13 событий без изменений. Проверены запуск без сети и продолжение урока после закрытия приложения на ранее установленной QA-сборке 1.0.
- Требуется постоянная подпись владельца. Скрипт `tool/sign_rustore.ps1` подписывает проверенный локальный APK, проверяет сертификат и записывает SHA-256. Запускается интерактивно владельцем. Публичный ключ подписи ещё не выбран.
- После подписания требуется проверка установки на отдельном телефоне или профиле. Смена сертификата исключает обновление поверх тестовой установки. См. [памятку](store/PHONE-QA.md).

Изменения входят в [Draft PR №24](https://github.com/1anchay/KVESMOS/pull/24).
