## Внедрение
1. Не заменять человека, зверя или космическую сущность вариантом Орби в другой одежде.
2. На первом этапе использовать лишь специально подготовленные обрезки/производные **с сохранением дизайна**, не обрезать наугад концепт-листы для продакшена.
3. Не выдавать косметические аксессуары на всех персонажей автоматически: нужны шаблоны размещения по каждому виду; несовместимые слоты показывать как недоступные.
4. Для экономии токенов: внедрить каталог и 2–3 персонажа в UI, затем расширить список без переписывания экрана.
5. Персонажи должны иметь оригинальную индивидуальность; сходство с героями существующих франшиз не считать лицензией.


## Новые готовые производные ассеты
- **Пикси** теперь имеет отдельный утверждённый рисунок: `01_approved/characters/pixie_sheet.png`.
- Для **Орби** подготовлен лист эмоций и отдельные PNG: `01_approved/orbi/emotions/`. Базовые эмоции: happy, wink_thumbsup, surprised, thinking, pout, sleepy.
- Эти файлы можно использовать как стартовые UI-ассеты, но они всё ещё требуют аккуратной интеграции и, при необходимости, финальной подгонки размеров под конкретные экраны.
