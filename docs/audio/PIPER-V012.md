# Локальная речь ES/DE в 0.12

Piper синтезирует собственные учебные тексты локально на компьютере разработчика. Это синтетическая речь; не актёрская запись и не английский голос с другим ярлыком. В приложение входят только AAC, модель и движок остаются вне APK.

Испанский: `es_ES-sharvard-medium`, speaker 0, 22050 Hz. [Карточка модели](https://huggingface.co/rhasspy/piper-voices/blob/main/es/es_ES/sharvard/medium/MODEL_CARD) указывает CC BY 3.0 для датасета [Sharvard_IJA](https://doi.org/10.7488/ds/75), Aubanel / García Lecumberri / Cooke, 2014. Немецкий: `de_DE-thorsten-medium`, [карточка](https://huggingface.co/rhasspy/piper-voices/blob/main/de/de_DE/thorsten/medium/MODEL_CARD), датасет [Thorsten-Voice](https://github.com/thorstenMueller/Thorsten-Voice), CC0. Репозиторий моделей объявляет MIT. Атрибуция и характер преобразований включены в APK: `PIPER-V012-NOTICE.txt`.

Сборка: `piper-tts==1.8.0`, отдельное Python-окружение, `python tool/render_languages_v012.py --model-dir PATH`. Модели загружаются из указанных каталогов Hugging Face (`.onnx` + `.onnx.json`). Точные SHA-256 фиксируются в `voice-v012-checksums.json`; повторная сборка должна использовать эти же файлы. Normal length scale 1.0; slow 1.30, отдельный синтез без снижения высоты тона. Если стохастическая генерация короткого слова даёт слишком короткий slow, применяется дополнительное замедление atempo с сохранением высоты тона. Проверяются фонемизация, конечность сигнала, длительность, RMS; нормализация -19 LUFS / -2 dBTP, mono AAC 80 kbps. Финальная проверка декодирует каждый AAC и сверяет checksum.

Один языковой диктор доступен всем персонажам; различия актёрских голосов не заявляются. Точный locale входит в ключ записи, одинаковый текст другого языка не может выбрать эту запись. Обычные/медленные фразы покрывают teaching cards, словарь, listening и реплики диалогов шести ES и шести DE уроков. Незаписанная произвольная фраза использует правильный системный TTS или читаемый текст. Французский и путунхуа используют `fr-FR` / `zh-CN`; для них новых локальных записей нет. Английские записи Kokoro сохранены без изменения.

Человеческое прослушивание этих ES/DE записей в текущей среде не выполнялось. Автоматическая проверка не заменяет редактора-носителя. Произношение и художественное качество не сертифицированы; это явное ограничение проверочного пакета.
