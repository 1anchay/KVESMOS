# Продолжение KVESMOS 1.5 · Galactic Adventure

Актуальная ветка codex/kvesmos-v15-galactic-adventure, создана от c465de8 ветки codex/kvesmos-study-flow / Draft PR #36. Сначала git status и git log, продолжать локальные изменения.

Прочитать docs/GALACTIC-ADVENTURE-1.5.md. Задание 1.5 реализовано частично: сцена мостика и планеты областей карты. Следующий приоритет — довести художественное качество командного центра и переработать карту в игровую сцену, затем первая законченная сюжетная глава. Экономику, ресурсы и новые режимы пока не добавляли.

Восемь адресных тестов и анализатор прошли. Сборка build/releases/KVESMOS-1.5-visual-stage-qa-universal.apk сохраняет Android 1.4.2+24 и прежнюю QA-подпись. Проверить финальные строки .tools/v15-build.log, .tools/v15-visual-retry.log, .tools/v15-final-target.log. Не выдавать этот этап за готовую 1.5.

QA эмулятор KVESMOS11_QA, serial emulator-5556. При необходимости ANDROID_AVD_HOME=.tools/avd. Снимки build/releases/KVESMOS-1.5-visuals. Генерация нового интерьера ImageGen завершилась сетевой ошибкой, используется оригинальная Flutter-графика и утверждённые персонажи.

Предыдущая база прошла 550 тестов, Android-цикл трёх уроков и офлайн-восстановление. Не повторять весь прогон без необходимости. Сохранить 300 уроков, пять курсов, SQLite, production-подпись, package ID и RuStore 1.0. Физические проверки микрофона, аудио и TalkBack открыты.

Технический приоритет следующего запуска: повторить установку финального APK и снять /galaxy и обе темы. AVD несколько раз завершался во время теста. Исходная сборка имела ошибку подготовки Dart isolate; последовательная пересборка с обновлённым кэшем восстановила запуск. Все команды сборки и тестов выполнять последовательно, чтобы build/flutter_assets не перезаписывался разными целями. Финальная кнопка карты ведёт на /galaxy, /map оставлен учебным темам. Светлый home-light.png просмотрен. map-light.png относится к предыдущему переходу /map и не подтверждает переработку галактики.
