# Архитектура 0.1

`domain` не зависит от Flutter/Supabase. `LearningRepository` обеспечивает SQLite и ресурсы. Riverpod предоставляет `AppController`, GoRouter управляет страницами. Backend заменяется реализацией `SyncRemote`.

## SQLite v1

- `settings(key,value)` — предпочтения, owner, состояние установки и lastSync.
- `lesson_packs(id,payload)` — отдельный JSON каждого установленного урока.
- `sessions(id,lesson_id,position,draft,done)` — попытки, позиция и черновики текста, пар и токенов.
- `events(id,payload,synced)` — неизменяемый журнал и outbox.

Drift создаёт v1 через `createAll`; generated-код включён. Используются WAL, foreign_keys, busy_timeout. При развитии схемы увеличивайте `schemaVersion`, добавляйте миграцию и тест открытия старой базы. Ошибка открытия не удаляет данные.

Ответ, переход и завершение фиксируются одной транзакцией. Устаревшая позиция отклоняет повторный submit. Запоздавший черновик не может перезаписать следующий вопрос. Закрытие после записи правильного ответа, но до анимации, возобновляет следующий шаг без потери награды.

Манифест содержит курс → раздел → тема → урок. Тело урока читается по требованию; импорт последовательный, список пакетов читает только ID. Удаление локальной копии не стирает прогресс. Восстановление — из встроенных assets, без сетевого каталога.

## Ответы и награды

Нормализация убирает регистр, лишние пробелы и основную пунктуацию; раскрывает явный небольшой список сокращений. Ответ сверяется с `answers`. Это не семантический переводчик: альтернативные корректные формулировки должны быть внесены авторами и протестированы. Пары проверяются по каждому соответствию; токены имеют отдельные индексы даже при одинаковом тексте.

Верный ответ — 10 XP один раз на `(session,exercise)`; завершение — 20 XP один раз на session. Повторный урок создаёт новую session. Ошибки ничего не отнимают. Уровень: `1 + XP ~/ 250`. Дневные задания отмечают фактический прогресс без дополнительного XP. Награды выводятся из истории.

Серия использует локальную календарную дату, сохранённую при событии. До занятия сегодня учитывается вчерашняя непрерывная серия. Разные часовые пояса и изменение часов — известная граница v0.1; защищённого рейтинга нет.

## SM-2

Адаптация [SM-2](https://www.super-memory.org/archive/english/ol/sm2source.htm): ease 2.5, минимум 1.3; правильный ответ = grade 4, ошибка = grade 1. Интервалы: 1, 6 дней, затем round(previousInterval × ease). Ошибка сбрасывает repetitions, назначает 1 день. Изменение ease соответствует формуле SM-2.

За UTC-день слово получает одну оценку планирования; любая ошибка понижает её до 1. Так быстрые повторы не раздувают интервалы. Счётчики учитывают все попытки. next = last + interval суток; mastery = min(repetitions / 6, 1). Освоение — эвристика, не сертификация. Слова связываются с упражнениями, где проверяется их лексика; сопоставление обновляет все слова набора.

## Синхронизация

Объединение неизменяемых событий по UUID, а не замена снимка прогресса. Push по 200, подтверждение outbox только после успеха. Потеря ответа сервера после записи безопасна благодаря идемпотентности. Pull по 500 с keyset-пагинацией по UUID. Одновременная вставка с меньшим UUID может прийти в следующий проход: каждый запуск перечитывает историю, поэтому событие не теряется навсегда.

Детерминированный replay по времени и ID вычисляет статистику и повторения. Owner-привязка предотвращает случайную отправку истории в чужой аккаунт. Для смены владельца нужна очистка локальных данных. Смена аккаунта приостанавливает синхронизацию.

Повторные попытки: старт, возврат в foreground, ответ в уроке, раз в минуту при работающем процессе. Постоянного фонового сервиса нет. UI показывает результат настоящего sync-запроса; отсутствие облака — локальный режим.

Ограничения: черновики, имя, тема и цель локальные. Между устройствами переносятся результаты, слова, XP и достижения; незавершённый урок начинается заново. Полный replay при большой истории потребует checkpoints и серверного курсора. Учебные материалы оригинальны; программные проверки не заменяют преподавательскую редактуру.
