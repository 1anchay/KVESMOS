# KVESMOS — готовая передача материалов Codex

**Версия:** 1.1 (21.10.2026). **Цель:** экономно доработать существующий Flutter-проект `dududud` / OrbitWords, превратив его в KVESMOS без потери данных.

## С чего начать
1. **`04_codex/CODEX_MASTER_PROMPT.md`** — основной промпт, который надо отправить в Codex (можно прикрепить этот ZIP или распаковать в рабочую папку проекта).
2. **`02_design/BRAND_GUIDE_CURRENT.md`** — актуальный визуальный стиль. Он **заменяет** устаревшие предложения из раннего `KVESMOS_Brandbook_v0.1.md`.
3. **`02_design/CHARACTERS.md`** — кто утверждён, чья графика есть и кого рисовать ещё не начали.
4. **`02_design/REWARDS_SPEC.md`** — сундуки, шанс выпадения, экономика, сохранение, защита от дублирования, а также новые изолированные PNG сундуков и эмоции Орби.
5. **`03_data/kv_catalog_draft_v2.json`** — предварительный машиночитаемый каталог (не миграция БД, не готовый код!).
6. **`05_references/OrbitWords_static_audit_2026-10-21.md`** — предыдущий статический аудит кода, читать только если работа касается замечаний P1/P2.
7. **`03_data/assets_manifest.csv`** — точные файлы, размеры, SHA256 и статус; **все изображения — концепт-арты/референсы**, не готовые PNG-спрайты.

## Самое важное
- **Выбранный Орби**: `01_approved/orbi/orbi_confirmed_by_user_screenshot.png` — именно робот, который выглядывает из-за планеты, с наклонным кольцом и подвесной звёздочкой. Исходный полный лист находится рядом. Не заменять другим Орби.
- **Персонажи утверждены**: Зиг, Мико, Рэйво, Астэр, Веспа, Нокс, Пикси; внешний вид взрослого профессора-лиса с очками.
- **Сундуки утверждены**: базовый бело-синий, туманный фиолетовый, сверхновая золото-синяя. Есть общий концепт-лист и отдельные PNG без фона для закрытого и открытого состояний каждого сундука.
- **Предметы**: 20 концептов, согласовано направление. Отдельные конечные файлы и корректные наложения на персонажей ещё не нарезаны и не проверены. Для Орби дополнительно есть лист из 6 эмоций и отдельные PNG-эмоции.
- Приложение **уже запускалось на реальном Android** и был пройден первый урок. **Микрофон не работает**; серверная синхронизация и iOS не подтверждены.
- Этот ZIP **не включает Flutter-проект, APK, ключи, токены, пароли**. Codex должен использовать **существующий локальный репозиторий**, не начинать новый проект.
- Текущие JSON, описания и эскизы служат техническим заданием, а не доказательством готовности функций. Не утверждать, что сундуки/инвентарь уже реализованы.

## Рекомендуемая последовательность
**Техническая диагностика микрофона → безопасный ребрендинг и визуальная основа → персонажи (первая волна) → локальные сундуки/инвентарь с тестами → UI/анимация → Android QA → расширение контента.**

Важное изменение относительно раннего брендбука: отказались от абстрактной буквы `K` и глянцевого 3D-логотипа. Лицо бренда — выбранный рисованный Орби.

## Как распаковать
В корне существующего проекта `dududud` создай папку `kvesmos_handoff` и распакуй **содержимое ZIP прямо внутрь неё** (чтобы получилось `dududud/kvesmos_handoff/00_READ_FIRST/START_HERE.md`). Путь указывать Codex относительно этой папки. Не заменять файл `pubspec.yaml`, приложение или Android-подписи.
