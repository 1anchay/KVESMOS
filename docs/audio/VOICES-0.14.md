# Локальная озвучка KVESMOS 0.14

В APK 809 уникальных записанных реплик, 1 618 AAC-файлов (обычная и замедленная версии), 33 068 659 байт. EN: 342 реплики / 684 файла; ES: 177 / 354; DE: 176 / 352; FR: 114 / 228. Все 1 024 файла версии 0.13 сохранены; добавлено 594 файла.

Декодирование всех файлов, опубликованные SHA-256, конечность отсчётов, ненулевая энергия, отсутствие цифрового переполнения и большая длительность замедленных версий проверены `tool/verify_voice_pack.py`. Продолжительность: 0,29–6,06 с. Это техническая проверка, не оценка произношения носителем.

Модели и лицензии прежние: [Kokoro](KOKORO-PROVENANCE.md), [Piper ES/DE](PIPER-V012.md), [французская SIWIS и атрибуция](VOICES-0.13.md). Веса моделей и движки генерации в приложение не включаются. Новые контрольные суммы: `voice-en-v014-checksums.json`, `voice-v014-checksums.json`; сохранены и прежние отчёты.

Китайский: лицензированного локального пакета нет. Системный голос используется только при подходящем языке, иначе доступны иероглифы, пиньинь с тонами и текстовая альтернатива. Наличие записей EN/ES/DE/FR и отсутствие китайской записи проверены на Android API36. Физическое прослушивание всех пяти языков остаётся блокером 1.0.
