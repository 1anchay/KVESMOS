# Ресурсы для следующего уровня качества KVESMOS

Обновление 0.5.0-dev.1: поставляется 94 английские реплики / 188 AAC-файлов / три синтетических стиля Kokoro (около 3,9 МБ), **0 студийных исполнителей**. См. [происхождение, лицензию и ограничения](audio/KOKORO-PROVENANCE.md). У Орби теперь отдельные программные глаза, зрачки, моргание и формы рта поверх исходного изображения; добавлена реакция на касание и разные профили движения Мико/Зига. Полного скелетного рига и фонемной синхронизации губ нет. Ниже сохранено описание исходного состояния 0.4.0-dev.3 и требований к будущим студийным материалам.

В 0.4.0-dev.3 **нет студийных голосов**. `assets/audio/voices/manifest.json` намеренно содержит пустой список. Приложение не загружает модели и записи из сети. Системный TTS остаётся резервом; число разных голосов показывается по фактическому списку устройства. Темп и высота сами по себе не создают новый голос.

## Записи

Реализован маршрут: точное совпадение персонажа, языка и текста → локальная запись → установленный системный голос → читаемый текст и объяснение проблемы. Файл воспроизводится нативным MediaPlayer на Android и AVAudioPlayer на iOS. Обычная/медленная версия, громкость, повтор, остановка и завершение имеют отдельные события. Запросы нумеруются: завершение старой записи не выключает новую анимацию. Индикатор разговора включается по фактическому событию TTS или успешному запуску локальной записи.

Нужны оригинальные записи с разрешением на распространение внутри бесплатного приложения. Для каждого исполнителя требуется документ о правах, допустимых способах использования, территории/сроке и необходимости атрибуции. Не добавлять голоса знаменитостей, клоны без согласия или модели с непроверенной лицензией. Сторонние модели и аудио в эту версию не включены.

| Персонаж | Направление для отдельного исполнителя |
|---|---|
| Орби | Тёплый, ясный наставник; мягкая поддержка после ошибки |
| Мико | Живой, любопытный спутник; естественный разговорный темп |
| Зиг Кварц | Энергичный экспериментатор, отчётливые короткие фразы |
| Рэйво | Бодрый тренер без давления и выкриков |
| Астэр | Спокойный объясняющий голос, чёткие логические паузы |
| Веспа | Уверенная, внимательная интонация исследовательницы |
| Пикси | Светлая, радостная интонация без искусственного писка |
| Нокс | Мягкий, сдержанный голос, без чрезмерно низкого тона |
| Профессор-лис | Рассудительный рассказчик, доступная новичку дикция |

Нужны английские учебные фразы и русские подсказки. Список учебных реплик первых шести уроков: `docs/audio/voice-script.tsv`, генерируется `python tool/export_voice_script.py`. Дополнительно записать реплики `CharacterCue` из `lib/ui/character_reactions.dart` с соответствующими персонажами. Обычная речь должна оставаться естественной, медленная — с нормальной интонацией, без разрыва каждого слова. При отсутствии отдельного медленного файла плеер использует скорость 0.8.

Формат: mono WAV PCM 16-bit 44.1/48 kHz либо AAC/M4A, без музыки и длинной тишины. Согласовать громкость между исполнителями, исключить клиппинг, проверить произношение специалистом. Учесть размер пакета; каждый аудиофайл, лицензионный документ и каталог с ними добавить в `pubspec.yaml` (Flutter не рекурсивно включает произвольные подкаталоги).

Пример записи в manifest, **это схема, а не имеющийся файл**:

```json
{
  "character": "orbi",
  "locale": "en-US",
  "text": "Hello!",
  "asset": "assets/audio/voices/orbi/hello.m4a",
  "slowAsset": "assets/audio/voices/orbi/hello-slow.m4a",
  "performer": "Имя или ID исполнителя по договору",
  "licenseAsset": "assets/audio/voices/licenses/orbi.txt",
  "redistributionApproved": true
}
```

Каталог отвергает внешние URL, выход за каталог, дубликаты и отсутствие подтверждения прав. CI проверяет наличие перечисленных файлов и документов. Юридическая проверка самих документов остаётся обязательной работой владельца ресурсов; boolean в JSON её не заменяет.

## Анимация

Есть десять состояний: idle, greeting, talking, listening, thinking, correct, support, celebration, surprise, goodbye. Движения конечные: наклон целого портрета, подпрыгивание/сдвиг, смена готовой позы Орби, частицы успеха, полоски речи. На существующей позе `orbi_thinking` добавлены программные веки для короткого моргания. Другие лица не перекрашиваются. Отключение анимаций и настройка реакций останавливают движения. Нет бесконечных таймеров.

Это **не скелетная анимация и не синхронизация губ**. Мико и остальные герои пока двигаются как цельные портреты. Рука Орби меняется вместе с готовой позой «палец вверх»; независимого движения руки нет. В `CharacterMoment.frames` можно передать последовательности готовых кадров для каждого состояния.

Для полноценной системы нужны:

- Отдельные прозрачные слои головы, тела, ближней/дальней руки и декоративных элементов для каждого героя; одинаковый размер холста и координаты опорных точек.
- Глаза: открытые, промежуточные, закрытые; рот: нейтральный, улыбка, поддержка, 4–6 разговорных форм. Слои без вшитого фона.
- Для покадрового варианта — кадры каждого состояния на общем холсте; idle/listening 8–12 кадров, жесты 12–24; отметка завершающей позы и длительности. Ориентир 512×512, масштабируемый до 66–150 логических пикселей.
- Для lip sync — размеченные интервалы фонем/viseme к каждому финальному аудиофайлу. Текущая реакция на состояние плеера не выдаётся за такую разметку.

Все используемые сейчас изображения взяты из переданного KVESMOS ZIP v2; новые изображения не генерировались.
