# Каталог бесплатных ресурсов

Проверены карточки авторов и заявленные лицензии. Архивы в этом аудите не импортировались. Для Kenney указана категория и предполагаемый рабочий формат; расширения и LICENSE точного архива проверяются при импорте. Для Quaternius форматы приведены по карточкам, доступность каждого формата в бесплатном варианте нужно проверить отдельно.

Для перечисленных пакетов авторы указали CC0. Это допускает коммерческое использование, изменение и распространение в пределах применимого права. Товарные знаки и случаи использования, требующие иных прав, CC0 не покрывает. Сохранить копию лицензии и имя автора в реестре проекта. [Условия CC0](https://creativecommons.org/publicdomain/zero/1.0/)

| Кандидат | Формат и назначение | Решение |
|---|---|---|
| [Quaternius Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) | FBX, GLB, Blend. Гуманоидный риг и движения. | P2. Использовать как референс тайминга ходьбы, суставные данные переносить только на проверенную анатомию. |
| [Quaternius Ultimate Animated Animal Pack](https://quaternius.com/packs/ultimateanimatedanimals.html) | FBX, OBJ, Blend, glTF по странице. Движение животных. OBJ пригоден для статичных форм. | P2. Изучить позы хвоста и опору, не заменять готовой моделью профессора-лиса. |
| [Quaternius Ultimate Space Kit](https://quaternius.com/packs/ultimatespacekit.html) | FBX, OBJ, Blend, glTF. Корабли и космические объекты. | P1. Силуэты декора и геометрические основы для офлайн-рендера с общей палитрой. |
| [Kenney Space Kit](https://kenney.nl/assets/space-kit) | 3D, планеты, корабли и модульные предметы. | P2. Проекции в Blender и ориентиры масштаба, освещение и текстуры адаптировать. |
| [Kenney Space Station Kit](https://kenney.nl/assets/space-station-kit) | 3D. Модули станции и предметы. | P2. Подходит для черновой геометрии помещений и для рендера станции на карте. |
| [Kenney Planets](https://kenney.nl/assets/planets) | 2D. Спрайты для сравнения силуэтов и заглушек в тесте камеры. | P2. Использовать в прототипе камеры. Рисованные миры в текущем дереве уже ближе к мосту. |
| [Kenney Particle Pack](https://kenney.nl/assets/particle-pack) | 2D VFX, заявленный tile 512×512. | P1. Взять маску свечения или искры. Пересобрать атлас небольшого размера с палитрой сцены. |
| [Kenney Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds) | Аудио, 70 файлов. Формат для приложения сверить с Android-плеером. | P1. Прослушать двигатель, дверь и сигнал консоли в контексте фраз. Свести громкость. |
| [Kenney UI Pack – Sci-Fi](https://kenney.nl/assets/ui-pack-sci-fi) | 2D, кнопки, слайдеры, панели. | P2. Использовать интервалы и маски для прототипа HUD. Адаптировать к существующим токенам цвета и типографике. |

Приёмка импорта — исходная ссылка, версия файла и SHA-256, лицензия авторского архива, выбранные файлы, изменение и место в приложении. Для внешних AI-работ, Sketchfab и OpenGameArt условия конкретного файла нужны до интеграции. Найденные пакеты персонажей полезны технически, но визуальная пригодность в утверждённом стиле не подтверждена.
