# KVESMOS 0.12 — Five Languages & Polish

База: `86e45d6cf756ea7e44423e8cfea67351b9d90a98`, PR #14. Ветка `codex/kvesmos-v012-five-languages-polish`, версия `0.12.0-dev.1+14`. Задание: [Issue #15](https://github.com/1anchay/KVESMOS/issues/15). Подготовлена проверочная Android-версия; изменения остаются в Draft PR и не объединены в main.

## Реализация

- Активный список находок содержит только нераспакованные сундуки. Транзакция сохраняет предмет до анимации; открытые grant IDs сохраняются навсегда. Полная коллекция даёт терминальное `consumedEmpty`, без замещающей валюты. Inventory JSON v2 читает v1; SQLite остаётся v1. Откат старого APK после записи inventory v2 не поддерживается.
- Добавлены шесть FR и шесть ZH уроков, по десять упражнений. Старые 40 файлов не изменены. `ru-fr` / `fr-FR`, `ru-zh` / `zh-CN`, упрощённый путунхуа. Иероглифы, тоновый пиньинь, объяснения до заданий, смысловые фрагменты вместо принудительного латинского ввода. Пунктуация и межсловные пробелы Hanzi нормализуются, акценты французского и тоновые знаки не стираются.
- Паспорт показывает реально начатые курсы, отдельные XP, серию, уроки, словарь, освоение SM-2 и языковые достижения. Общий профиль, косметика и миссии используют прежний журнал; паспорт ничего не начисляет.
- После языка/цели новый пользователь явно выбирает напоминания и виджет либо «Не сейчас». Запросы не повторяются после сохранённого решения. Отказ не блокирует уроки. Для прежних пользователей — добровольное предложение, настройки доступны постоянно. Запрос закрепления не называется успешной установкой.
- Семантические цвета для профиля, находок, сцены сундука, баннеров и карты. Сцена сундука больше не принуждает dark theme. Android-виджет поддерживает светлую/тёмную системную тему и выбор приложения.
- Встроен OFL-поднабор Noto Sans SC (переименован KVESMOS Hanzi), включая необходимые знаки пиньиня; [контрольные суммы](hanzi-font.json). Оригинальные иллюстрации сохранены.

## Android и обновление

Настоящий офлайн-сценарий API 36: **9:40, passed** ([журнал](verification/v012/android-cycle.log)). Пять первых уроков пройдены через интерфейс: по 120 XP на язык, суммарно 600 XP. Переключение языков не создаёт новых наград. Проверены обычная и медленная локальные записи ES/DE, французский и китайский с доступным текстом, иероглифы и тоновые знаки, открытие → примерка → применение предмета → исчезновение сундука → безопасный повторный вызов. Wi-Fi и мобильная сеть были выключены. Воспроизведение подтверждено нативным плеером; эмулятор запущен без аппаратного звука, человеческое прослушивание не заявляется.

Проверены системный отказ от уведомлений и продолжение онбординга, последующее разрешение в настройках, подтверждение закрепления виджета, его состояние после каждого из пяти уроков и обе темы. Доставка запланированного уведомления проверялась в 0.11; в 0.12 повторно проверены разрешения, настройки и сохранение, без утверждения о повторной проверке доставки по таймеру.

Обычный APK из `lib/main.dart` установлен через `adb install -r`, с предварительной резервной копией и сверкой сертификата. [Построчное сравнение старой SQLite](verification/v012/data-preservation.json): все **13 событий, 3 сессии, 54 прежние настройки и 40 прежних пакетов** сохранены без изменения; добавлены 12 пакетов и 13 настроек. SQLite остаётся v1, прежние XP, черновики, инвентарь и экипировка сохранены. Никакого uninstall или очистки данных. Нативная база содержит английский прогресс; одновременные языковые черновики и синхронизация дополнительно покрыты тестами репозитория.

ARM64 APK проверяется отдельно от x64-сборки эмулятора: `dev.orbitwords.orbitwords`, versionCode **14**, сертификат SHA-256 `b8c558730dd20651119dd74b014b31ff51f076af208198dc79e05e51a0dca8be`. Архив Actions и APK сверены по SHA-256; ELF — ARM64, интеграционного тестового entrypoint нет. 353 прежних ассета идентичны 0.11; общий manifest речи дополнен. Итоговые APK, SHA256SUMS и JSON-проверка находятся в `build/releases/` (не коммитятся).

Первые две попытки нативного прогона прерваны аварией QEMU/SwANGLE в Windows (0xc0000005). Полный прогон завершился с `-gpu host -feature -Vulkan`; это настройка QA, а не изменение приложения.

## Границы проверки

iOS на Windows не собирается; WidgetKit по-прежнему отсутствует. ARM64 APK проверен как артефакт, а взаимодействие выполнялось на x64 Android QA-эмуляторе, не на физическом ARM64-телефоне. Курсы — начальные маршруты, не полные программы A1; редакторское прослушивание и проверка носителями остаются необходимыми перед публичным релизом. FR/ZH не имеют встроенного голосового пакета. Личные устройства не затрагивались: все установки выполнены только в выделенном `OrbitWords_QA`.
