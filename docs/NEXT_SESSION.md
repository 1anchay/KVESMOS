# KVESMOS 1.5 · рисованная команда

Рабочая ветка `codex/kvesmos-v15-galactic-adventure`. Draft PR #37 открыт в `codex/kvesmos-study-flow`. Android сохраняет версию 1.4.2+24. Следующий запуск начинайте с `git status -sb` и последних коммитов в этой ветке.

## Герои

В приложении используются утверждённые рисунки KVESMOS. На мостике Мико показывает голограмму, Орби встречает ученика. Зиг, Астэр, Рэйво, Веспа, Нокс и профессор-лис получили цельные фигуры для экрана команды. Пикси появляется при выдаче награды. Четыре коллекционных аватара используют портреты с прозрачностью. Учебные реплики, ответы и сундук используют CharacterMoment. Речь привязана к событиям LearningAudio.playback.

Исходники лежат в docs/design-handoff/01_approved/characters. Повторный экспорт семи фигур выполняет `python tool/export_crew_illustrations.py`. Предыдущие составные модели и внешний 3D-прототип выведены из приложения по результатам визуального просмотра. История экспериментов сохранена в Git. Подробности по ассетам и неподготовленным движениям приведены в ART-ASSETS-1.5.md и ANIMATION-READINESS.csv.

## Проверки

- Flutter analyzer и адресные тесты character_stage, companion_playback, alive_experience и rewards. Логи последнего запуска лежат в .tools/crew-final-analysis.log и .tools/crew-final-test.log.
- Android-сценарий integration_test/art_vertical_slice_test.dart проходит через обе темы, урок, исправление ошибки и выдачу предмета. Использует временную базу для теста.
- integration_test/companion_art_demo_test.dart показывает всех девятерых в покое, при верном ответе и при поддержке. Видео и кадры записывает tool/capture_learning_polish.py. Материалы текущего запуска находятся в build/releases/KVESMOS-illustrated-crew, галерея — в подпапке gallery.
- На этой машине для QA AVD KVESMOS11_QA (emulator-5556) используйте `-gpu host -feature -Vulkan`. Запускайте Flutter-тесты и сборки последовательно. Для проверочного APK используйте lib/main.dart и существующую QA-подпись. Логи Android, проверки подписи и установки имеют префикс .tools/crew-final-.

## Следующая визуальная проверка

Открыть проверочную сборку на физическом Android, оценить лица и жесты при обычном масштабе, сверить реакцию при начале/остановке озвучки. Индивидуальная походка и самостоятельные циклы моргания остаются открытыми задачами. Перед развитием этих движений учитывать отклик владельца на текущие рисунки.
